# axr2718.github.io

Personal academic website of Adrian Rodriguez, published at <https://axr2718.github.io>.

Built with Jekyll using the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT License). Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it to the `gh-pages` branch.

## Where things live

- `_pages/about.md` – home page text
- `_bibliography/papers.bib` – publications (`selected={true}` also shows a paper on the home page; `preview=` sets its thumbnail from `assets/img/publication_preview/`)
- `assets/pdf/cv.pdf` – the CV shown on the CV page
- `_data/socials.yml` – contact and profile links
- `_config.yml` – site settings
